## 1. 干净标签数据投毒和脏标签数据投毒各有什么优缺点？前者一定比后者好吗？

干净标签数据投毒是指攻击者修改训练样本，但标签仍然保持正确；脏标签数据投毒则是同时修改样本及其标签，使错误标签直接进入训练集。

脏标签投毒的优点是实现相对简单、攻击效果较为直接，容易导致模型整体性能下降；缺点是样本内容与标签不一致，较容易被人工检查或异常检测发现。干净标签投毒的优点是隐蔽性更强，更容易绕过基于标签一致性的检测；缺点是构造难度更高，攻击成本也更高。

因此，干净标签投毒并不一定比脏标签投毒更好。前者更隐蔽，后者更直接，二者各有优缺点，适用于不同攻击场景。

## 2. 基于 k-NN 的中毒数据检测有什么优缺点？这种检测方法对干净标签数据投毒和脏标签数据投毒攻击都有效吗？

基于 k-NN 的检测方法主要根据样本在特征空间中的近邻关系来判断其是否异常。如果一个样本的标签与其邻近样本大多不一致，或者它明显偏离同类样本分布，就可能被判定为可疑样本。

这种方法的优点是原理直观、实现简单，对分布异常较明显的中毒样本有较好的检测效果，尤其对脏标签投毒较有效。因为脏标签样本通常会出现“特征像一类、标签却属于另一类”的情况，因此容易被 k-NN 发现。

其缺点是检测效果依赖于特征表示质量，在高维空间中距离度量可能不够可靠，而且对于精心构造、隐蔽性较强的干净标签投毒样本，k-NN 往往不容易识别。因此，这种方法对脏标签投毒通常更有效，而对干净标签投毒的检测能力相对有限。

## 3. 为了防范数据投毒攻击，还能想到什么样的方法来提前预防这类恶意攻击对模型的可用性和完整性产生破坏？

为了防范数据投毒攻击，可以从多个环节采取措施：

1. 在数据收集阶段：应尽量保证数据来源可靠，并通过多人标注、交叉审核等方式减少恶意样本混入
2. 在训练前：结合异常检测、聚类分析、损失值分析等方法筛查可疑样本
3. 在训练阶段：采用鲁棒训练方法，例如对可疑样本降权、使用鲁棒损失函数或集成学习，以减小中毒样本的影响
